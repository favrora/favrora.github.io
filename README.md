# Product Legal Pages

Static legal and support pages published with GitHub Pages for independent mobile products by
David Voskanyan.

## LabelFit

LabelFit is an evidence-first mobile tool for comparing nutrition labels and ingredients from two
real product packages. The public pages document the product, its local-first data model, support
channels, and legal terms.

| --- | --- |

| Support | [Support](https://favrora.github.io/label-fit/support.html) |

## Implementation

- Semantic HTML with responsive, dependency-free CSS
- Static hosting through GitHub Pages
- No tracking scripts, advertising SDKs, forms, or third-party runtime dependencies
- Separate product, privacy, terms, and support routes

Legal copy is intentionally maintained separately from application code so public store links remain
stable across mobile releases.
